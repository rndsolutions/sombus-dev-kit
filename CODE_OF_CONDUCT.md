# Code of Conduct

This project follows the [Story Object Model Code of Conduct](https://github.com/storyobjectmodel/som/blob/main/CODE_OF_CONDUCT.md), so the same standards apply here as in the standard it implements.

Report concerns about conduct in this repository to the maintainers through GitHub's private vulnerability reporting, or by email to the repository owner. Concerns about the SOM project itself go to admin@storyobjectmodel.com.
