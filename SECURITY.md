# Security

Please don't report security problems in public issues.

Use GitHub's **private vulnerability reporting** on this repository (Security → Report a vulnerability). We'll acknowledge the report, agree a fix and a disclosure date with you, and credit you unless you'd rather not be named.

In scope: the executors, runner and registration code in this repository. Problems in the SOM schemas or the skill library itself belong upstream at [`storyobjectmodel/som`](https://github.com/storyobjectmodel/som); contact admin@storyobjectmodel.com for anything sensitive there.

Never include real newsroom content or credentials in a report. Use synthetic data.
